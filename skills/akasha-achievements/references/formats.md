# 进度格式

本站备份为 `{"format":1,"records":{"ys:成就ID":记录}}`，游戏前缀为 `ys`、`sr`、`zzz`。记录字段：`completed` 布尔值、`date` 空字符串或日期、`updatedAt` 毫秒整数、`device` 本地设备标识。保留旧备份的 `note` 及 `uiaf` 元信息，不新增备注功能

`uiaf` 元信息含 `current`、`status`、`timestamp`。按 [UIAF 标准](https://uigf.org/zh/standards/uiaf.html)，v1.1 的状态 0 / 1 未完成，2 / 3 已完成；v1.0 没有状态字段，按已完成导入。未知时间戳为 `253402271999`，日期为空，已知时间按 UTC+8 转为日期

多阶段成就使用各自原始游戏 ID，即使展示名称相同也不合并成一个进度键。UIAF 仅导入或导出 `ys`，本站备份保留全部游戏。UIAF 导入记录使用新的更新时间，覆盖文件列出的原神项；文件未列出的项不变。完整备份按 `updatedAt` 合并，相同时戳使用网站一致的 JSON 文本排序

直接设置完成状态会清除不再对应的 UIAF 原状态；日期未知的完成项以标准未知时间戳导出。需要 `current` 目标值时使用目录的 `target`，已导入的部分进度及领奖状态优先原样保留

脚本修改前把原文件复制为 `.bak-时间-随机标识`，通过同目录临时文件及原子替换写入。损坏数据、重复 UIAF ID、非整数、非法状态等导致命令失败，不进行部分导入。初始化和导出不覆盖已有目标文件
